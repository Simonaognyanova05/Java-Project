# Smart Shipment Tracking frontend

React application for the Smart Shipment Tracking project. The app uses Create
React App and Node.js 20 or newer.

```sh
npm ci
npm start
```

The development server runs at `http://localhost:3000` and proxies `/api` to
the Spring Boot backend at `http://localhost:8080`. Start the backend separately.

The shipment creation screen is available at `/shipments/new`.
